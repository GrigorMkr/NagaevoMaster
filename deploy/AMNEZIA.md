# AmneziaWG на VPS

Обфусцированный VPN (AmneziaWG 2.0) — **совместим с приложением AmneziaVPN**, устойчивее к блокировкам DPI, чем обычный WireGuard.

| Сервис | Порт |
|--------|------|
| API HTTPS | 443 **TCP** |
| AmneziaWG | 443 **UDP** |
| Сайт | REG.RU (без изменений) |

## Установка на сервер

```powershell
npm run vps:amnezia
```

Скрипт:
- отключает старый WireGuard (`wg0`);
- ставит AmneziaWG из **официального PPA** `ppa:amnezia/ppa`;
- генерирует обфускацию AWG 2.0 (Jc, S1–S4, H1–H4, I1);
- сохраняет конфиги в `artifacts/amnezia/` (не коммитить).

Если после установки VPN не стартует — **перезагрузите VPS** (нужен DKMS-модуль ядра), затем снова `npm run vps:amnezia`.

## Подключение в AmneziaVPN

### Вариант A — импорт готового конфига (рекомендуется)

1. Откройте **AmneziaVPN** на телефоне/ПК
2. **+** → **Импорт конфигурации** / **Import**
3. Выберите `artifacts/amnezia/amnezia-1.conf` (ПК) или `amnezia-2.conf` (второе устройство)
4. Включите подключение

### Вариант B — QR-код

1. Откройте `artifacts/amnezia/amnezia-1.png` на экране ПК
2. В AmneziaVPN: **+** → **Сканировать QR-код**

### Вариант C — через «Свой сервер» в приложении

Если конфиг не импортируется:

1. **+** → **Свой VPN-сервер**
2. IP: `161.104.18.17`, пользователь: `root`, SSH-ключ с ПК (`~/.ssh/nagaevomaster_vps`)
3. Протокол: **AmneziaWG**, порт **443**

Приложение само доустановит сервер (можно после нашего скрипта — выберите «переустановить»).

## Удалить старый WireGuard

- В приложении **WireGuard** (не Amnezia) удалите туннель на `161.104.18.17`
- Дальше используйте только **AmneziaVPN**
